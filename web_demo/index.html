✕ Exposed environment configuration file (/.env) OWASP A05:2021 · Security Misconfiguration · CWE-540 High Risk
Observed Evidence: GET /.env returned HTTP 200 with sensitive database credentials (DB_PASSWORD=demo_secret_pass; APP_KEY=base64:...)

Remediation: Deny public web server access to dotfiles and relocate configuration outside the web root.

✨ Gemini AI Code Fix & Analysis
Nginx Block Directive: # Block access to hidden configuration files location ~ /\.(?!well-known).* { deny all; return 404; } Apache Directive (.htaccess): <FilesMatch "^\."> Require all denied </FilesMatch> Verification: Run curl -I http://target/.env (must return HTTP 403 or 404).
✕ Cleartext password login over unencrypted HTTP OWASP A02:2021 · Cryptographic Failures · CWE-319 High Risk
Observed Evidence: Authentication form containing <input type="password"> was served over plain HTTP at /.

Remediation: Configure TLS 1.2+ and enforce HTTPS across the application to protect credentials in transit.

✨ Gemini AI Code Fix & Analysis
Nginx HTTPS Redirect Configuration: server { listen 80; server_name your-app.local; return 301 https://$host$request_uri; } Verification: Run curl -I http://target/ (should return HTTP/1.1 301 Moved Permanently to https://).
! Content Security Policy is missing OWASP A05:2021 · Security Misconfiguration · CWE-693 Medium
Observed Evidence: The root response does not include the Content-Security-Policy header.

Remediation: Define a restrictive policy, starting with default-src 'self', and allow only required sources.

✨ Gemini AI Code Fix & Analysis
Nginx Baseline CSP Header: add_header Content-Security-Policy "default-src 'self'; script-src 'self'; style-src 'self'; object-src 'none'; base-uri 'self';" always; Verification: Run curl -I http://target/ (response must include Content-Security-Policy).
✓ MIME-sniffing protection is missing OWASP A05:2021 · Security Misconfiguration · CWE-693 Low
Observed Evidence: The root response does not include X-Content-Type-Options: nosniff.

Remediation: Set X-Content-Type-Options: nosniff.

✨ Gemini AI Code Fix & Analysis
Nginx Configuration: add_header X-Content-Type-Options "nosniff" always; Verification: Run curl -I http://target/ (verify X-Content-Type-Options: nosniff header is present).
